The X99 Build

One secondhand Huananzhi X99-BD4 board turned into an inference server that I keep extending: soldering its PCIe lanes, flashing its BIOS, waking it over the network, unlocking the mining GPUs, and pooling two GPUs from two vendors to serve one model.

It now runs Proxmox VE 9.2 with one LXC container per GPU: the unlocked CMP 40HX on my patched NVIDIA driver and an AMD Radeon VII on ROCm, with the host keeping both drivers. llama.cpp RPC pools the two cards across containers to serve Qwen3 32B. The models load from the Intel NVMe, mounted read-only, and Ubuntu stays on it as a fallback.

Rebuilding it

The Ubuntu install, now the fallback on the NVMe, is described in X99-Recreation, an Ansible playbook that rebuilds it from scratch. The Proxmox host is set up by one script that mirrors the playbook’s nvidia_cmp40hx role. The playbook’s roles:

  • base, tailscale: packages, hostname, user groups, Tailscale SSH.
  • nvidia_cmp40hx: installs the 610.57.04 userspace, pins and holds the driver packages, builds the cmpunlocker modules, and installs the boot units below.
  • amdgpu_power: the Radeon VII power cap.
  • ollama, cuda_toolkit, plus optional mistralrs and benchmarks roles.

What happens at boot

  1. The patched NVIDIA modules load and try their own Gen2 retrain, which fails on this board’s root port.
  2. cmp40hx-gen2-retrain reprobes the driver so the card advertises Gen2, then retrains the link from the root port: 2.5 → 5 GT/s. It checks the PCI ID first, so it won’t touch a different card if the slots change.
  3. cap-cmp40hx locks the CMP’s idle clock to 300 MHz (cmp40hx-uncap releases it for inference).
  4. amdgpu-power-cap finds the Radeon VII by PCI ID and sets its cap to 200 W.
  5. Only then do the containers start, so container 102 gets a CMP that is already unlocked, at Gen2 x16, with its 8 GiB BAR1. A container can’t retrain the link or change clocks, so all of this stays on the host.

The unlock is volatile and the patched modules are built per kernel, so a kernel hook rebuilds cmpunlocker for every new kernel before it’s booted.
