kvsnap: mistral.rs vs llama.cpp on an 8GB Card

Making a 15.6k-token shared prompt cost milliseconds instead of a minute on one secondhand GPU: llama.cpp slot snapshots first, then mistral.rs with a small Rust patch and a token-level check that cached answers match. The same models rerun on both engines ran up to 37% faster on mistral.rs.
